# iNear Updates

Public distribution of signed iNear macOS app updates. Source code is maintained in a separate private repository. This repository contains release binaries and public release notes only.

Download the latest iNear-macOS.zip from Releases, extract iNear.app and place it in a writable Applications folder. From version 0.4.14 onward, Settings → Updates → Update and Restart installs future versions automatically, without a GitHub account.

Requires macOS 14+ on Apple silicon. Builds are Apple Development-signed and are not notarized.
